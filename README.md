# MC QUIC Tunnel - P2P Minecraft Tunnel without Port Forwarding
I created this app with **Claude Sonnet 4.6**. to replace some VPN, because them sometimes works with high ping.
## About
This app offers Free Quick Tunnel for Minecraft Hosting without VPS and Port Forwarding.   
It works with Iroh thats breaks through NAT.     
And Quic provides better connection over TCP.

## Set Up
1. Download [App](https://github.com/gwill1337/mc-quic-tunnel/tree/main/app)
2. Open to LAN Minecraft (*Port*) 
3. Follow the instructions from the app

## Troubleshooting
* Sometimes Iroh connetion may have high ping or even doesn't connect. This can be caused by a strict NAT or a complex network infrastructure. Try using a different VPN.
